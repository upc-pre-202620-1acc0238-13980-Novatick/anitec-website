# ANITEC Website

Landing page for ANITEC, a livestock management and veterinary coordination project by Novatick.

## Run locally

Open `index.html` in a browser. No package installation or build is required. Images and fonts are included in `assets/`.

## Structure

- `index.html`: page content and semantic structure.
- `styles.css`: responsive styling and animations.
- `script.js`: navigation, dialogs and motion effects.
- `assets/`: reference images, logo and fonts.

## Workflow

Create feature branches from `develop` and open pull requests targeting `develop`. Prepare releases before merging into `main`. Use Conventional Commits in English.

## Validation and limitations

JavaScript syntax and local asset references were checked. Browser visual and interaction testing remains pending. The app download URL, contact channel and legal documents have not been supplied; their links show informational notices. Typography and icons approximate the supplied PDF.
